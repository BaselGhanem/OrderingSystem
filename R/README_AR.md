# نظام المرتجعات — النسخة النظيفة + P1

هذه الحزمة تحتوي نظام المرتجعات الحالي فقط. لا يوجد اعتماد تشغيلي على نظام الطلبيات الحالي.

## التشغيل
ابدأ من `index.html` أو `login.html`.

## Firebase
المشروع: `dad-returns`

Collections المستخدمة:
- `returns_requests` — طلبات المرتجعات
- `returns_requests/{requestId}/audit` — سجل تدقيق مستقل بتوقيت Firestore Server
- `return_allocations` — دفتر حجز ذري لكل Sale ID لمنع تجاوز الكمية المباعة عند التزامن
- `returns_pharmacies` — دليل الصيدليات للمندوبين
- `returns_sales_chunks` — المبيعات التاريخية الفعلية
- `returns_imports` — سجل رفع ملفات المبيعات
- `returns_users_config` — المستخدمون وإعدادات الدخول (PBKDF2 Hash فقط، بدون كلمة سر صريحة)

لا يوجد Firebase Authentication في هذه النسخة حسب قرار المشروع الحالي.

## مسار الموافقات
مندوب → رئيس قسم الطلبيات → المشرف → مدير السوق → المالية → جاهز للسحب → تمت الفوترة

## المبيعات التاريخية
تُرفع من `Admin.html` وهي مستقلة بالكامل عن Ordering System. لا يمكن إنشاء مرتجع إلا لسجل بيع تاريخي مطابق للعميل/الصنف/الفاتورة/Batch، وبحد أقصى الكمية الأصلية المتبقية.

## تحسينات P1 المنفذة
1. `return_allocations`: إنشاء/تعديل/حذف المرتجع يحدّث حجز الكمية داخل Firestore Transaction واحدة.
2. Audit Trail: الأحداث الجديدة تُحفظ في Subcollection مستقلة باستخدام `serverTimestamp()`.
3. File fingerprint: بصمة ملفات المبيعات أصبحت SHA-256 كاملة لمنع تكرار الملف.
4. Pagination/Queries: صفحات المراجعة تحمل 75 سجلاً في كل دفعة، تاريخ المندوب 100، وسجل الرفع 50.
5. تمت إضافة `firestore.indexes.json` للاستعلامات المركبة الجديدة.

## النشر
بعد تحديث الملفات على الاستضافة، انشر Rules وIndexes من داخل هذا المجلد:

```bash
firebase deploy --only firestore
```

ملاحظة: الـIndexes الجديدة قد تحتاج وقتاً قصيراً حتى تصبح حالتها Enabled في Firebase Console بعد النشر.

## ترحيل أي بيانات سابقة
عند فتح `Admin.html` لأول مرة بعد هذه النسخة، يفحص النظام `return_allocations/__meta__`:
- إذا لم توجد مرتجعات سابقة، يهيئ دفتر الحجز تلقائياً.
- إذا وجدت مرتجعات سابقة، يظهر قسم **سلامة دفتر الكميات** وزر **مزامنة دفتر الكميات**. نفّذه مرة واحدة قبل السماح بإدخال مرتجعات جديدة.
